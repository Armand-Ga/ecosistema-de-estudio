# Ecosistema de Estudio

Aplicación web interactiva para estudiar, repasar y practicar contenidos mediante flashcards y quizzes, con la opción de competir en sesiones multijugador en vivo.

## Características

- **Flashcards** para repasar conceptos de forma rápida.
- **Sistema de quizzes** con varios modos:
  - Opción múltiple
  - Ordenar procesos
  - Relacionar conceptos
  - Modo aleatorio automático
- **Sesiones multijugador en vivo** con código de sala y marcador compartido, usando Firebase.

## Tecnologías

- JavaScript (vanilla)
- Tailwind CSS (vía CDN)
- Firebase

## Cómo usarlo

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.

No requiere instalación ni dependencias adicionales.

## Estructura

La aplicación está contenida en un solo archivo (`index.html`), que incluye el HTML, los estilos y la lógica.
